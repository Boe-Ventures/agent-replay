# Chrome Web Store listing draft

## Name

Agent Replay

## Short description

Local flight recorder and true tab video capture for localhost development.

## Detailed description

Agent Replay preserves what happened in a local web app before a coding agent was attached. It records structured, privacy-redacted evidence for any shell-capable agent, provides replayable DOM history for humans, and can capture faithful tab pixels for product demos.

Use the extension on `localhost` or `127.0.0.1` alongside the open-source Agent Replay sidecar. Session identity survives navigation, the popup shows an explicit recording state, and **Record polished demo** streams a user-initiated WebM recording to local storage through an MV3 offscreen document.

Agent Replay is local-only: there is no account, hosted backend, advertising, or proprietary AI dependency. Form values are masked by default and secrets are redacted before evidence reaches disk. The extension does not capture microphone audio.

## Category

Developer Tools

## Single purpose

Capture privacy-redacted debugging evidence and user-initiated demo video from local web-development tabs for local replay, agent inspection, and export.
